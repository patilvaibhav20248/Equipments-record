# Equipments-record

IT Hardware & Dead Stock Equipment Register for Computers, Printers, and Projectors.

## Features
- **Categorized Inventory Management**: Separate and unified management for Computers (PC - WDN), Printers, and Projectors.
- **Excel Bulk Import & Parser**: Multi-sheet automatic parsing of Excel stock sheets.
- **Excel Spreadsheet Attachment Viewer**: High-contrast vertical and horizontal preview of hardware specifications.
- **Department & Course Breakdown**: Course-level analytics, operational status indicators, and KPI summary counters.
- **Export Capabilities**: Generate comprehensive Excel audit reports.

## Getting Started
To run locally:
```bash
node server.js
```
Then open `http://localhost:3000/` in your browser.
